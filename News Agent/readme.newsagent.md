## 📌 Overview

The **News Agent** is an AI-powered component of the **Agentic Layer**.

Its job is simple:

> **Fetch live news for top-ranked assets, deduplicate identical stories, and analyze them to determine market sentiment, impact, catalysts, and risks.**

The agent uses the Serper API to scrape web news and passes it to Groq's LLM to generate a structured analysis containing:

- 📰 Event grouping
- 📈 Overall sentiment & impact
- 🎯 Relevance scores
- 🚀 Catalysts & Risks

The result is saved to disk where it can be picked up by the **Decision Agent**.

# 🎯 What Does the News Agent Do?

The News Agent reads the latest output from the Market Scanner, finds the top candidates, and then:

```text
                SERPER NEWS API
                       │
                       ▼
                 📰 NEWS AGENT
                       │
             Two-Stage Deduplication
            (URL -> LLM Semantic Events)
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
     🟢 POSITIVE    ⚪ NEUTRAL   🔴 NEGATIVE
          │            │            │
          └────────────┼────────────┘
                       ▼
          Catalysts, Risks, Impact Score
```

# 📥 Input Format

The News Agent automatically dynamically finds and parses the latest output generated by the Market Scanner (e.g., `market_scan_20260825.json`).

It specifically looks for the `candidates` array to extract the `symbol`:

```json
{
  "candidates": [
    {
      "symbol": "NVDA",
      "rank": 1,
      "opportunity_score": 93.2
    }
  ]
}
```

# 🧠 Analysis Logic

The News Agent uses a sophisticated multi-step pipeline to prevent hallucinations and duplicate noise:

## 1. Retrieval
Fetches up to 15 recent news articles for the asset using the `google.serper.dev/news` endpoint.

## 2. Stage-1 Deduplication (Python)
Drops any articles that have the exact same URL.

## 3. Stage-2 Deduplication (LLM)
Passes all articles to Groq to semantically group articles that are covering the exact same underlying event (e.g., assigning them an `event_id`).

## 4. Final Analysis (LLM)
The LLM evaluates each event based on 5 strict criteria:
- **Entity Relevance**: Is the company actually involved?
- **Market Materiality**: Could this affect the stock?
- **Specificity**: Is it about the company or just the industry?
- **Recency**: Is it recent?
- **Source Quality**: Is the source credible?

## 5. Score Calculation (Python)
A deterministic python function calculates a final `news_score` from 0-100 based on weighted metrics:
- Sentiment (30%)
- Market Impact (25%)
- Relevance (20%)
- Recency (15%)
- Source Quality (10%)

# 🔗 Integration With Other Agents

The News Agent does **not** make the final trading decision. Its output becomes one input to the Decision Agent, alongside the Market Agent and Options Agent.

---

# 🚫 What the News Agent Does NOT Do

The News Agent is responsible for **news and sentiment only**.

It does **not**:

- ❌ Perform technical or chart analysis
- ❌ Execute trades
- ❌ Provide options strategies
- ❌ Make the final `TRADE/PASS` decision

# 🚀 Quick Start

## 1. Install Dependencies

```bash
pip install -r ../requirements.txt
```

## 2. Configure Environment

Create a `.env` file in the `News Agent` folder:

```env
GROQ_API_KEY=your-groq-key
SERPER_API_KEY=your-serper-key
```

## 3. Run the Agent

```bash
python news_agent.py
```

*Note: You can edit `sandbox_mode=True` inside the script to run mock tests without spending API credits.*
